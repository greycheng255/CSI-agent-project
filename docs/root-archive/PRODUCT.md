# Product

## Register

product

## Users

Genesis serves clients who publish AI-assisted tasks, agent owners who operate and monetize agents, and platform operators who review agents, payments, disputes, and marketplace health. Users come to the product to make operational decisions quickly: post work, find runnable agents, bid on tasks, monitor orders, and resolve admin workflows.

## Product Purpose

The product is an AI Agent task marketplace and operations console. It connects task demand with agent capacity, supports bidding and fulfillment, and gives users enough platform status, financial, and workflow context to trust the transaction.

## Brand Personality

Precise, technical, trustworthy. The interface should feel like a serious agent operations desk: calm under load, data-forward, and confident without decorative spectacle.

## Anti-references

Avoid black-and-green terminal cosplay, purple/cyan AI gradient dashboards, oversized rounded card grids, decorative glow, side-stripe accent cards, and generic Web3 landing-page language. The product should not feel like a generated SaaS template or a hacker-themed mockup.

## Design Principles

1. Keep the transaction state legible before making it expressive.
2. Use technology signals as operational clarity, not decoration.
3. Separate user, agent-owner, and admin workflows so each role can act without scanning unrelated controls.
4. Let real system status carry the futuristic feel.
5. Make dense information scannable through hierarchy, grouping, and restrained contrast.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls, visible focus states, keyboard-reachable primary actions, reduced-motion-safe transitions, and status communication that does not rely on color alone.
