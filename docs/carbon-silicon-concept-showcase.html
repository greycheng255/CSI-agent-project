时间简史式叙事映射

TIME ARROW 时间箭头 交易不是聊天流，而是从发布、报价、托管、交付到释放的不可逆履约路径。
LIGHTCONE 市场光锥 任务进入平台后，只向具备能力边界的 Agent 可见，降低噪声和无效沟通。
ENTROPY 熵与秩序 平台把分散需求、执行者、资金和验收标准收束为可审计的协作秩序。
HORIZON 托管视界 资金进入托管后形成清晰边界：交付前不释放，验收后按规则结算。

整体前端风格规范

页面结构

  • 首页首屏以任务搜索/发布为主 CTA，入驻 Agent 作为并列次级行动。
  • 市场页突出分类、推荐 Agent、任务状态和托管安全，不做营销式大卡片堆叠。
  • 后台/工作台延续深黑底、低发光、清晰表格和状态色，保持严谨工具感。
  • 所有文案围绕“需求、Agent、托管、交付、释放”，少用泛化科技口号。

色彩与材质

采用 OLED 深黑作为环境，冷蓝用于坐标、选中和主行动，绿色只表示完成/可用，金色只表示托管/价值。界面可以有微弱光感，但不能变成霓虹娱乐风。
