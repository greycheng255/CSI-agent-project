# Genesis 平台 K3s 部署指南

---

## 📁 上传文件

将整个 `docker-images` 文件夹上传到服务器，例如放到 `/opt/deploy/`：

```
/opt/deploy/
├── genesis-all_20260623-232559.tar   ← 所有镜像（572 MB）
├── docker-compose.yml                ← 备用（不需要）
└── deploy/                           ← 部署配置
    ├── 00-namespaces.yaml
    ├── 01-rbac.yaml
    ├── 02-storage.yaml
    ├── 03-backend.yaml        ← ⚠️ 需要修改数据库地址
    ├── 04-frontend.yaml
    ├── 05-bridge.yaml
    ├── 06-agent-main.yaml
    ├── 07-agent-heartbeat.yaml
    ├── 08-ingress.yaml        ← 可选，域名访问用
    └── deploy.sh
```

---

## 🔧 第 1 步：修改配置

**必须修改** `03-backend.yaml` 中的数据库配置，打开文件找到下面 4 行改成你的实际值：

```yaml
- name: DB_HOST
  value: "替换为你的数据库IP"       # ← 改
- name: DB_PORT
  value: "5432"                    # ← 改（如果是 1Panel 装的 PostgreSQL，端口可能不是 5432）
- name: DB_USER
  value: "genesis_user"            # ← 改
- name: DB_PASSWORD
  value: "genesis_password"        # ← 改
```

还有对外访问地址：

```yaml
- name: UPLOAD_BASE_URL
  value: "http://替换为你的服务器IP:30080"   # ← 改成服务器公网 IP
```

> 如果还没有 PostgreSQL 数据库，先在 1Panel 的「数据库」里装一个 PostgreSQL，创建数据库名为 `genesis_db`。

---

## 🚀 第 2 步：导入镜像

```bash
cd /opt/deploy

# 导入所有镜像到 k3s
k3s ctr images import genesis-all_20260623-232559.tar

# 验证导入成功（应看到 4 个镜像）
crictl images | grep 20260618
```

---

## 🚀 第 3 步：一键部署

```bash
cd /opt/deploy/deploy

# 方式一：执行部署脚本
sh deploy.sh

# 方式二：手动逐个部署
kubectl apply -f 00-namespaces.yaml
kubectl apply -f 01-rbac.yaml
kubectl apply -f 02-storage.yaml
kubectl apply -f 03-backend.yaml
kubectl apply -f 04-frontend.yaml
kubectl apply -f 05-bridge.yaml
kubectl apply -f 06-agent-main.yaml
kubectl apply -f 07-agent-heartbeat.yaml
```

---

## 🔍 第 4 步：检查状态

```bash
# 查看所有 Pod 是否 Running
kubectl get pods -n genesis
kubectl get pods -n openclaw-cloud

# 查看 Service（确认端口映射）
kubectl get svc -n genesis

# 如果 Pod 没启动，查看日志
kubectl describe pod -n genesis <pod名称>
kubectl logs -n genesis <pod名称>
```

---

## 🌐 第 5 步：访问

部署成功后，浏览器打开：

```
http://<服务器公网IP>:30080
```

默认管理员账号：`13800000001`，验证码登录。

## 🛠️ 常用运维命令

```bash
# 查看所有 Pod
kubectl get pods -n genesis
kubectl get pods -n openclaw-cloud

# 实时查看日志
kubectl logs -n genesis -l app=genesis-backend -f
kubectl logs -n genesis -l app=genesis-agent -f
kubectl logs -n openclaw-cloud -l app=openclaw-bridge -f

# 重启某个服务
kubectl rollout restart deployment/genesis-backend -n genesis
kubectl rollout restart deployment/genesis-frontend -n genesis

# 删除所有部署（从头再来）
kubectl delete namespace genesis
kubectl delete namespace openclaw-cloud
```

## ⚠️ 常见问题

**1. Pod 一直 Pending？**
```bash
kubectl describe pod -n genesis <pod名>
```
通常是资源不足或 PVC 未绑定。

**2. 后端连不上数据库？**
确认服务器防火墙开放了 PostgreSQL 端口（通常是 5432），且 `03-backend.yaml` 中 DB_HOST 填的是内网 IP 而非 127.0.0.1。

**3. 镜像导入后不生效？**
确认用的是 `k3s ctr images import` 而非 `docker load`，k3s 用的是 containerd。

**4. 上传文件 404？**
确认 `UPLOAD_BASE_URL` 配置的 IP 是可以从浏览器访问的公网 IP。
